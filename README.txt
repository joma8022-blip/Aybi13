ПУБЛИКАЦИЯ НА GITHUB PAGES

1. Распакуйте архив.
2. Загрузите index.html и папку assets в корень репозитория. Не загружайте сам ZIP.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.

Текст, дата и адрес меняются в index.html. Музыка запускается после нажатия на розу. Видео без звука играет по кругу.
